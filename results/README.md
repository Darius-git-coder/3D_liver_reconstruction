# Results

This directory contains the curated thesis artifacts that accompany the codebase.

- `ablation/`  
  Final model comparison table and suite-level summary exported from the documented `128^3` ablation study.
- `splits/`  
  Sanitized case-id version of the persisted train/val/test split used throughout the thesis.
- `regularization/`  
  Plots, raw CSV exports, summary tables, and LaTeX tables for the empirical regularization analysis of the selected baseline model.
- `ultrasound_probe/`  
  Evaluation summaries, finetuning history, and qualitative figures for the controlled ultrasound-like finetuning study.
- `slice_distribution/`  
  Appendix artifacts for the comparison against the classical regression baseline.

Absolute machine-local paths were removed from the public copies. Where path-like fields remain, they are relative to the repository structure.
